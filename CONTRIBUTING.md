# Contributing

This is a student project, so the contribution process is intentionally simple.

## Suggested Improvements

- Improve graph readability
- Add better evidence grading
- Add more diseases and drugs
- Improve deployment setup
- Add tests for backend endpoints

## Local Setup

```bash
chmod +x run.sh
./run.sh
```

Before submitting changes, check that:

- the frontend starts
- backend API endpoints respond
- no large generated files are committed
